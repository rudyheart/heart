# 策略与性能

首先计算有界合法动作。将带朝向的移动展开成回合边，每条保留两个子步的目标；缓存官方冻结地图。用位图表示领地、星格、开放轮廓及外沿。候选路线粗筛后对最优候选做外沿泛洪和双方完整计分，以投影分差变化衡量抢地和形状成本。

扩张从领地内可达出口搜索二、三、四段折线，保留不同的转弯与回家路线。候选净收益按完成回合数及敌方抵达线路的安全余量折扣；终盘领先时更保守。若近端没有合适闭合，沿己方领地寻找更安全且仍有高价值格的远端边界。每步复核己方当前位置、朝向、路线、领地变化、现有和未来开放轮廓；受威胁时尝试提前回家。回家路线保守排除中间子步刚闭合又立即出门的动作，这是可行解上的剪枝。

敌方可达时间按转向和起步格加速搜索；停机从出生点和剩余停机回合计算。把当步能直接切断的旧轮廓纳入决策，再比较短追击可否赶在对方最快回家前完成。近身时对逐子步同格或换位做检查。可限时调用的 SDK 环境额外通过引擎副本推演实际敌方方向。多个动作存活情况相同时，最近几次朝向用于区分直行倾向。未获确认的模拟结果不会计为存活。

参数在 bots/team121_agent/config.py。策略总软预算 95ms，折线枚举 28ms，20 条候选，32 回合宏计划，34 回合对手预测，4 回合截断。POSIX 主线程且未占用系统定时器时，单次模拟最多 12ms；其他线程或系统使用几何评估。截止前已有结果或保底方向可以立即返回。官方 200ms 是整个请求往返的上限，策略内计时与裁判计时分别报告。
